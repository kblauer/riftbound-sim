# packages/db

Supabase types and the RiftHunt card seed script.

- **Local only.** `scripts/seed-cards.ts` refuses any non-local `SUPABASE_URL` unless run with
  `--remote`. Do not pass `--remote` unless the user specifically asks.
- **Seed flow:** one `/bulk/cards` fetch plus one paged `/cards/search?q=set:{code}&unique=prints`
  per set, joined on `printing_id`, validated with zod (`src/rifthunt.ts`), then only changed
  rows are upserted and `catalog_meta.version` is bumped. `seed:dry-run` fetches and validates
  without writing.
- **RiftHunt etiquette:** at most one seed run a day, about a second between requests, no
  per-card crawling, a `User-Agent` naming the project.
- **Keys:** `printing_id` identifies a printing, `oracle_id` a card across printings.
  `riftboundId` is not unique; never key on it.
- **Types:** `src/database.types.ts` is generated by `pnpm db:types` from the local database.
  Regenerate after every migration; do not edit by hand.
- `CATALOG_COLUMNS` in `src/index.ts` must match `catalogCardSchema` in `packages/protocol`.
